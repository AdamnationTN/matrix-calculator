__this a simple matrix calculator made in C++__
---
_this is a first C++ project that i made for the learning purposes so you might expect the unfinished messy code you are free to look/contribute at the code project and see how it works :)_
---
if you wanna clone this project type in the terminal
``git clone https://github.com/AdamnationTN/matrix-calculator.git``

## What features are implemented:
- ***2x2 and 3x3 Matrix support***
- ***Addition ,Substraction and Matrix Multiplcation by scalar or by other Matrix***
- ***Determinant operator***
- ***Transpose operator***

## What Features are not implemented yet
- ***Inverse Matrix***
- ***Adjoint Matrix**
